# mentor-matching

CYF mentor matching platform — a monorepo holding both applications.

## Layout

| Path | What lives there |
| --- | --- |
| [`frontend/`](frontend/) | React + Vite + Tailwind app |
| [`backend/`](backend/) | NestJS + Prisma + PostgreSQL API |
| [`docs/design/`](docs/design/) | Design system: [DESIGN.md](docs/design/DESIGN.md), [HANDOFF.md](docs/design/HANDOFF.md), and reference screen captures |

## Contributing

Read [CONTRIBUTING.md](CONTRIBUTING.md) for the git workflow (branch off `develop`, conventional commits, squash before review). Issues are labeled `frontend` or `backend` — the label tells you which directory the work belongs in.
